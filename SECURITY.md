# Security Policy

## Reporting a vulnerability

Please report security issues **privately**. Do not open a public issue, pull
request, or discussion for a suspected vulnerability.

- Use **[GitHub private vulnerability reporting](https://docs.github.com/en/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability)**
  on the affected repository (the **Security → Report a vulnerability** tab), or
- email **team@tartarusai.dev** with the details and a way to reach you.

Please include: the repository and version, a description, reproduction steps or
a proof of concept, and the impact you observed.

## What to expect

- We aim to acknowledge a report within a few business days.
- We'll confirm the issue, keep you updated on remediation, and credit you in the
  advisory if you'd like.
- Please give us reasonable time to ship a fix before any public disclosure.

## Scope

This policy covers the code in the Tartarus AI repositories. The hosted service
(`api.tartarusai.dev`, `dash.tartarusai.dev`) is also in scope — report issues
there the same way.

We don't currently run a paid bug-bounty program, so no monetary reward is
promised. We do appreciate and acknowledge good-faith reports.
