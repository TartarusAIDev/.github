# Support

Need help with Tartarus? Here's where to go.

## Using the product

- **Docs & onboarding** — [tartarusai.dev](https://tartarusai.dev/?utm_source=github&utm_medium=readme&utm_campaign=support&utm_content=docs)
- **Account, tokens, billing & usage** — [dash.tartarusai.dev](https://dash.tartarusai.dev/?utm_source=github&utm_medium=readme&utm_campaign=support&utm_content=dashboard)
- **CLI install** — `pip install tartarus-console`

## Something's broken or missing

Open an issue on the repository it relates to:

| Area | Repo |
|---|---|
| The `tartarus` CLI | [tartarus-console](https://github.com/TartarusAIDev/tartarus-console/issues) |
| TypeScript SDK | [tartarus-sdk](https://github.com/TartarusAIDev/tartarus-sdk/issues) |
| MCP server | [tartarus-mcp](https://github.com/TartarusAIDev/tartarus-mcp/issues) |
| API examples | [tartarus-cookbook](https://github.com/TartarusAIDev/tartarus-cookbook/issues) |
| Benchmark | [refusal-bench](https://github.com/TartarusAIDev/refusal-bench/issues) |
| Guides / lists | [uncensored-ai-guide](https://github.com/TartarusAIDev/uncensored-ai-guide/issues) · [awesome-uncensored-ai](https://github.com/TartarusAIDev/awesome-uncensored-ai/issues) |

Before filing: search existing issues, and include your OS, versions, and steps
to reproduce.
